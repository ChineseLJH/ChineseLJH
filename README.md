### 💡 关于我 (About Me)

我是一名来自沈阳工业大学（SUT）计算机专业的 24 级在读本科生。我对技术的热爱不局限于纯粹的代码逻辑，更在于**让代码与物理世界产生交互**。

我的技术栈贯穿了机器人的完整神经系统：从基于 STM32/ESP32 的底层硬件控制，到基于 Linux/Docker 的边缘计算架构，再到基于 ROS2 的 3D 激光 SLAM 算法部署。我致力于在**具身智能（Embodied AI）**与**异构边缘计算**领域深耕。

- 🎓 **当前状态**：沈阳工业大学计算机科学与技术专业（2024级）在读
- 🏆 **核心荣誉**：Robocon 全国大学生机器人大赛**国赛一等奖** | 蓝桥杯 C/C++ **省赛一等奖**
- 📜 **专业认证**：CCF 生成式人工智能系统应用能力认证 (LMCC) 一级 | IITC 工业互联网开发工程师
- 🔭 **目前聚焦**：FAST-LIO2/Point-LIO 算法的跨平台工程化落地，边缘设备（Jetson/RK3588）的异构加速部署。

### 📂 开源矩阵 (Featured Repositories)

基于我的全栈开发经验，我将项目划分为以下几个核心领域：

#### 🧠 1. 传感器与算法中间层
* **[LIVOX-MID-360-Deployment](链接到你的那个雷达仓库)**: (近期核心) 基于 Livox MID-360 的 3D 激光 SLAM 部署方案。包含 FAST-LIO2 与 Point-LIO 在 Jetson 等边缘设备上的 Docker 化一键部署，以及针对机器狗场景重写的 IMU 姿态监听与串口热插拔重连机制。

#### ⚡ 2. 嵌入式底层“神经末梢”
* **[MySTM32](https://github.com/ChineseLJH/MySTM32)**: STM32 进阶开发实践库。记录了我在底层硬件驱动、RTOS 及各类传感器控制上的工程积累，是机器人底层运动控制（如 Robocon 备赛）的基石。
* **[MyESP32](https://github.com/ChineseLJH/MyESP32)**: 针对 AIoT 与无线通信场景的工程集合。侧重于轻量级设备的 Wi-Fi/Bluetooth 通信及边缘数据采集。

#### 🖥️ 3. 跨平台交互界面
* **[Qt-Projects](https://github.com/ChineseLJH/Qt-Projects)**: 基于 Qt 框架的上位机与 GUI 开发库。用于搭建与底层硬件或 ROS 节点进行数据交互的可视化控制台与调试工具。

*(注：如果你有那个 USB 3.0 Hub 的开源硬件图纸仓库，也可以作为第 4 点“高速硬件电路设计”加进来)*
